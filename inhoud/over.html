Over deze site

Deze site legt uit wat Ploegapp is en hoe je hem gebruikt. Hij verzamelt zelf niets over jou.

Privacyverklaring van deze website

  • Geen cookies, ook geen "functionele". Daarom is er ook geen cookiemelding.
  • Geen statistieken, analysediensten, trackers of advertenties.
  • Geen externe lettertypen, scripts, video's of social-mediaknoppen: alles komt van deze site zelf.
  • Geen formulieren: je vult hier nergens iets in.
  • Geen JavaScript: de site bestaat alleen uit tekst, opmaak en afbeeldingen.

Een automatische controle bij elke publicatie laadt alle pagina's en keurt de site af als er toch een cookie, script of verzoek naar een andere website in zit.

Hosting

De site staat op GitHub Pages. Zoals elke webserver ontvangt GitHub bij een bezoek technisch je IP-adres. GitHub bewaart dat volgens zijn eigen privacyverklaring tijdelijk in logbestanden, voor beveiliging en om misbruik tegen te gaan. Wij hebben daar geen toegang toe en gebruiken het niet. GitHub (Microsoft) valt onder het EU-VS Data Privacy Framework.

De app zelf staat niet op GitHub, maar bij een hostingpartij die elk korps zelf kiest. Zie Privacy en veiligheid.

Verzonnen voorbeelden

Alle namen, korpsen, voertuignummers en oefeningen op deze site zijn verzonnen. Brandweer Duinwijk bestaat niet. De screenshots worden automatisch gemaakt van de nieuwste versie van de app, gevuld met deze verzonnen gegevens. Er komen nooit echte gegevens van een korps op deze site.
